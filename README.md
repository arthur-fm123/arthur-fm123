**Principais características:**
- Desenvolvimento de site com HTML, CSS e JavaScript.
- Apresentação da proposta socioambiental.
- Foco em sustentabilidade e inclusão digital.
- Site publicado para demonstração do projeto.

**Tecnologias:** HTML · CSS · JavaScript
